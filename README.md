# Муравей Ленгтона · практика TDD на C#

Работайте в паре. В `LangtonsAnt.Tests` пишите тесты, в `LangtonsAnt.Core` реализуйте мир и муравья. Проект `LangtonsAnt.Console` уже готов. Откройте `LangtonsAnt.slnx` в IDE или выполните команды ниже из папки решения.

## Запуск

Понадобится SDK .NET 10. При первом запуске тестов NuGet скачивает пакеты, если их ещё нет в локальном кеше.

```sh
dotnet run --project LangtonsAnt.Console -- --demo
dotnet test
dotnet run --project LangtonsAnt.Console
```

- Первая команда показывает 1 000 записанных ходов на поле 61×19. Пауза между ходами — 30 мс. Для обновления кадров на месте нужно окно терминала не меньше 64×24 символов. `.` обозначает белую клетку, `#` — чёрную, `^ > v <` показывают направление муравья. Цвет клетки под стрелкой подписан отдельно.
- Вторая запускает тесты. В начале один тест красный: `World.GetColor` ещё выбрасывает `NotImplementedException`.
- Третья запускает вашу модель. До реализации `Ant.GetSteps` она покажет начальный кадр и укажет, какой метод нужно дописать. Для анимации и клавиш откройте обычный терминал. Пробел ставит на паузу и продолжает, `N` делает один ход на паузе, `Q` завершает запуск.

## Работа в паре

1. **Красный.** Один участник формулирует поведение и пишет тест. Запустите его и убедитесь, что он падает по ожидаемой причине. Для первого цикла тест уже подготовлен.
2. **Зелёный.** Второй участник пишет минимум кода, нужный для прохождения теста. Запустите все тесты.
3. **Рефакторинг.** Улучшите имена и структуру там, где это нужно, и снова запустите тесты. Поменяйтесь ролями перед следующим циклом.

## Правила и контракт

Поле бесконечное. Все нетронутые клетки белые. Координата `X` растёт вправо, `Y` — вниз. Обе координаты могут быть отрицательными. `World.GetColor(position)` возвращает текущий цвет, а `World.SetColor(position, color)` задаёт его.

За один вызов `Ant.Step()` муравей смотрит на цвет **текущей** клетки, поворачивает на 90° вправо на белой или влево на чёрной, меняет цвет этой клетки на противоположный и перемещается на одну клетку в новом направлении. Свойства `Position` и `Direction` отражают его состояние после хода.

`AntStep` хранит исходную позицию `From`, новую позицию `To`, новое направление `Direction`, цвет покинутой клетки после перекраски `FromColorAfter` и цвет клетки назначения `ToColor`.

`Ant.GetSteps(count)` возвращает ленивую последовательность. Сам вызов состояние не меняет. Каждый полученный элемент продвигает муравья на один ход. Для нуля последовательность пуста, для отрицательного числа при перечислении возникает `ArgumentOutOfRangeException`.
